# Compatibility

## Current development baseline

| Component | Supported line | Verified minimum |
| --- | --- | --- |
| .NET | 10 | SDK 10.0.302 / runtime 10.0.10 |
| ASP.NET Core Identity | 10 | Microsoft.Extensions.Identity.Stores 10.0.10 |
| Marten | 9 | 9.21.0 |
| OpenIddict | 7 | 7.6.0 |

Dependency ranges exclude the next major version until its compatibility is reviewed. Preview dependencies are not part of the supported baseline.

This document describes the repository foundation, not a published compatibility guarantee. The table will become a release contract when the first package is published.

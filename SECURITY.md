# Security Policy

## Supported versions

No public package has been released yet. Once releases begin, the latest stable major version will receive security fixes. Additional support commitments will be documented with each stable release.

## Reporting a vulnerability

Do not open a public issue. Use GitHub's private vulnerability reporting for this repository. If that feature is unavailable, contact the Innovorium maintainers privately through the organization profile.

Include the affected package and version, impact, reproduction details, and any suggested mitigation. Maintainers will acknowledge a complete report within five business days and coordinate disclosure after a fix is available.

Never include production credentials, personal data, or active tokens in a report.
